# Как проверить бота

> **Статус: бот развёрнут и работает на VPS** → **@YourBot**
> Сервис `english-tutor` — `active` + `enabled` (автозапуск при перезагрузке).
> Живой лог: `tail -f '/path/to/english-tutor-bot/bot.log'`

Три уровня проверки — от быстрого «всё ли цело» до живого чата в Telegram.

**Самое короткое, что можно сделать прямо сейчас:**

```bash
cd "/path/to/english-tutor-bot"
npm run verify            # 97 тестов, ~5 с
npm run rehearse          # весь диалог на mock-модели, ~3 с
npm run rehearse:live     # реальный DeepSeek + реальный xAI TTS, ~40 с
```

Всё зелёное → бот рабочий; для живого чата переходите к разделу 2.

## 2. Живой Telegram-чат

### 2.1. Запустить бота

Сначала убедитесь, что запущен whisper-proxy (нужен для голосового ввода):

```bash
curl -s http://127.0.0.1:3011/health
# ожидаем: {"status":"ok","service":"whisper-proxy"}
```

Если пусто — поднимите:

```bash
cd /path/to/whisper-proxy && nohup node server.cjs > /tmp/whisper.log 2>&1 &
```

Затем запустите бота в **переднем плане**, чтобы видеть логи:

```bash
cd "/path/to/english-tutor-bot"
npm run build
node dist/index.js
```

Ожидаемый вывод:
```
INFO: tutor core ready
INFO: English Tutor online as @YourBot
```

### 2.2. Что нажимать в Telegram

Откройте **@YourBot** и напишите `/start`.

> ⚠️ В `.env` задано `ALLOWED_USER_IDS=1512571026`. Если у вас другой Telegram ID,
> бот ответит `Access denied.` — либо добавьте свой ID, либо очистите переменную
> (`ALLOWED_USER_IDS=`), чтобы пустить всех.

Чек-лист прохождения:

| # | Действие | Что должно произойти |
|---|---|---|
| 1 | `/start` | 3 шага онбординга: приветствие → кнопки уровня → кнопки цели, затем первая реплика урока |
| 2 | Отправить текст с ошибкой: `I go to London yesterday` | Ответ с `🎤` + `✅` исправлением + `📝 Why` + `🎯` новыми словами + `🗣` вопросом; приходит **голосовое** |
| 3 | 🎤 Записать голосовое: «I visited the museum last week» | Бот расшифрует речь и ответит с исправлениями |
| 4 | `/scenario` → Hotel booking | Бот войдёт в роль портье; **в ответе не должно быть `✅`/`📝`** |
| 5 | 3–4 реплики в сценарии | Диалог держится в роли |
| 6 | `/summary` | Ошибки из сценария (отложенные) + слова + закрытие сессии |
| 7 | `/pronounce` | Слово-«ловушка» + `🎤 Say this word: …` |
| 8 | Записать голосом это слово | Оценка произношения; при ошибке — «say it again» |
| 9 | `/stats` | Сессии, реплики, словарь, бейджи |
| 10 | `/words` | Слова по статусам new / learning / learned |
| 11 | `/level` | Уровень, ladder, baseline; `/level up` — повышение |
| 12 | `/cancel` | Выход из сценария/дрилла |

### 2.3. Если что-то не так

Логи идут в stdout. Типовые сообщения:

| Сообщение | Причина / что делать |
|---|---|
| `Access denied.` | Ваш Telegram ID не в `ALLOWED_USER_IDS` |
| `🎙 Couldn't catch that` | whisper-proxy не запущен или не разобрал речь |
| `🔇` в начале ответа | TTS не сработал — смотрите `TTS synthesis failed` в логе |
| `😅 I missed that.` | DeepSeek вернул ошибку (ключ/квота) |
| `Conflict: terminated by other getUpdates` | Бот уже запущен в другом месте — убейте дубль |

Проверить, не запущен ли бот уже дважды:

```bash
pgrep -af 'node dist/index.js'
```

### 2.5. Установка с нуля (если сервиса ещё нет)

> ⚠️ **Сначала исправьте владельца файлов.** Каталог проекта принадлежит `root`, а юнит
> запускается от вашего пользователя — при таком раскладе бот не сможет писать `data/tutor.db`
> и кэш TTS. Один раз выполните:
>
> ```bash
> cd "/path/to/english-tutor-bot"
> sudo chown -R $USER:$USER .
> sudo chmod 600 .env          # токены не должны быть доступны всем
> sudo -u "$USER" test -w data && echo "OK: data writable"
> ```

Установка сервисов:

```bash
cd "/path/to/english-tutor-bot"
sudo cp english-tutor.service /etc/systemd/system/
sudo cp /path/to/whisper-proxy/whisper-proxy.service /etc/systemd/system/
sudo systemctl daemon-reload
sudo systemctl enable --now whisper-proxy english-tutor
systemctl status english-tutor whisper-proxy
```

Остановить / перезапустить:

```bash
sudo systemctl restart english-tutor
sudo systemctl stop english-tutor
```

> `whisper-proxy` нужен для голосового ввода и тоже должен быть `enabled`, иначе после
> перезагрузки VPS распознавание речи отвалится.

## 3. Смотреть, что происходит внутри

После нескольких сообщений состояние лежит в `data/tutor.db`:

```bash
sqlite3 data/tutor.db "
  SELECT '— users —';        SELECT id, level, target, session_count FROM users;
  SELECT '— sessions —';     SELECT id, type, topic, turn_count, error_count, state FROM sessions;
  SELECT '— errors —';       SELECT correction, repeats FROM error_log ORDER BY repeats DESC LIMIT 5;
  SELECT '— vocabulary —';   SELECT word, status FROM vocabulary;
  SELECT '— achievements —'; SELECT label FROM achievements;
"
```

Отдельные проверки:

```bash
# какие модели/ключи реально видит бот
node -e "import('./dist/config.js').then(c=>console.log({tts:c.TTS_PROVIDER,voice:c.TTS_XAI_VOICE,codec:c.TTS_CODEC,lang:c.TTS_LANGUAGE}))"

# живой синтез одной фразы (создаст файл и покажет путь)
TTS_CACHE_DIR=/tmp/ttsdemo node -e "import('./dist/speech.js').then(async s=>console.log(await s.textToSpeech('Hello, this is a British voice test.')))"
```
